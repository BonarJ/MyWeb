Flashcard Belajar Web & GitHub

Klik kartu untuk membalik jawaban 3D, saring materi sesuai topik, dan tandai kartu yang sudah Anda kuasai—semuanya berjalan murni dengan HTML5 & CSS3 tanpa JavaScript.

Uji Pemahaman Cepat (Tanpa JS)

Pilih salah satu jawaban di bawah untuk langsung memeriksa hasilnya dan melihat skor otomatis.

🎯 Skor Kuis: / 4 Benar
1. Selektor CSS mana yang memungkinkan kita mengubah gaya halaman berdasarkan checkbox yang dicentang di dalamnya?
Penjelasan: Pseudo-class :has() berfungsi sebagai parent selector sehingga elemen induk seperti body dapat merespons status :checked pada elemen anak.
2. Agar sisi belakang kartu 3D tidak terlihat menembus sisi depan saat belum dibalik, properti apa yang digunakan?
Penjelasan: backface-visibility: hidden menyembunyikan bagian punggung elemen saat diputar 180 derajat pada sumbu Y atau X.
3. Apa nama file utama yang harus diunggah ke repositori GitHub agar langsung tampil sebagai beranda di GitHub Pages?
Penjelasan: Server statis seperti GitHub Pages secara otomatis mencari file bernama index.html sebagai pintu masuk utama situs Anda.
4. Bagaimana cara membuat tombol "Reset" yang mengosongkan semua pilihan input tanpa JavaScript?
Penjelasan: Elemen <button type="reset"> di dalam <form> merupakan fitur bawaan HTML untuk mengembalikan seluruh checkbox dan radio button ke kondisi awal.

Langkah Mudah Mengunggah Halaman Ini ke GitHub Pages

Karena aplikasi ini hanya terdiri dari 1 file HTML mandiri (CSS sudah menyatu di dalamnya), Anda bisa mengonlinekannya dalam 2 menit:

1

Buat Repositori Baru

Masuk ke akun GitHub Anda, klik tombol New Repository, beri nama (misalnya flashcard-belajar), dan pilih Public.

2

Unggah sebagai index.html

Unduh kode halaman ini, ubah namanya menjadi index.html, lalu unggah melalui menu Add file → Upload files di GitHub dan klik Commit changes.

3

Aktifkan GitHub Pages

Buka tab Settings → Pages pada repositori Anda. Pada bagian Branch, pilih main lalu klik Save. Website Anda akan aktif dalam ~1 menit!

💡 Tips Kustomisasi: Bagaimana cara menambah kartu baru?

Cukup salin salah satu blok <article class="flashcard-item" data-cat="html">...</article> di dalam kode HTML, lalu ganti ID uniknya menjadi flip-10 dan master-10 agar kartu baru berfungsi mandiri.

🎨 Tips Desain: Bagaimana cara mengganti warna tema?

Ubah nilai variabel warna pada bagian :root di paling atas blok <style>, misalnya mengganti --accent: #4f46e5; dengan warna favorit Anda.
